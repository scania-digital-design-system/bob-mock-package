## React wrappers and types

`@scania/tegel-react` is generated by `@stencil/react-output-target` 1.6.2 (`createComponent`
over `@lit/react`); events map to `on<Event>` (`onTdsClick`). Consumers:
`import { defineCustomElements, TdsButton } from '@scania/tegel-react'` plus
`@scania/tegel/dist/tegel/tegel.css`. Types in `@scania/tegel`:
`dist/types/components.d.ts` (`Components.TdsButton`, `JSX.TdsButton`, …), per-component
`dist/types/components/<dir>/<name>.d.ts`, custom elements `dist/components/tds-<name>.js`.

## Badge — `tds-badge` (shadow DOM)

| Prop (attr) | Type | Default | Reflected |
|---|---|---|---|
| `value` | `string` | `''` | yes |
| `isHidden` (`hidden`) | `boolean` | `false` | no |
| `size` | `'lg' \| 'sm'` | `'lg'` | yes |
| `tdsAriaLive` (`tds-aria-live`) | `'off' \| 'polite' \| 'assertive'` | `'polite'` | yes |

No events, slots or methods. `tdsAriaLabel` is internal state (always `''`), not a prop.
Logic (`checkProps` on load and on `value`/`size` change): if `parseInt(value)` is a
number and size ≠ `sm`: `shape = 'pill'` when `value.length >= 2`; size forced `lg`;
`text = '99+'` for 3+ digits, else the number. Non-numeric and `sm` render no text.

```
<tds-badge role="status" aria-label="" aria-live="{tdsAriaLive}"
  class="tds-badge tds-badge-{size} [tds-badge-pill] [tds-badge-hidden]">
  #shadow: <div class="tds-badge-text" aria-hidden="true">{text}</div>
```

Styles: `.tds-badge` radius 12px, bg `--tds-badge-background-color`, centred; `-sm` 8×8
(lh 8px); `-lg` 20×20 (lh 20px); `-pill` inline-block, width unset, padding-x 8px;
`-hidden` display none; `.tds-badge-text` 12px bold, colour `--tds-badge-color-text`.
Vars: background → danger-default #d1001b; text → text-inverse-base #fff.
Unused: `--tds-badge-border-radius` (24px), `--component-badge-font-weight` (700).

## Button — `tds-button` (light DOM, scoped)

| Prop (attr) | Type | Default |
|---|---|---|
| `text` | `string?` | — |
| `type` | `'button' \| 'submit' \| 'reset'` | `'button'` |
| `variant` | `'primary' \| 'secondary' \| 'ghost' \| 'danger'` | `'primary'` |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg'` | `'lg'` |
| `disabled` | `boolean` | `false` |
| `fullbleed` | `boolean` | `false` |
| `modeVariant` | `'primary' \| 'secondary' \| null` | `null` |
| `animation` | `'none' \| 'fade'` | `'none'` |
| `tdsAriaLabel` | `string?` | — |
| `name`, `value` | `string?` | — |

Slots `label`, `icon`. Native `click`. `onlyIcon` when no text and no label slot. Enter
keydown/keyup toggles `.active`.

```
<tds-button class="[tds-mode-variant-{mv}] [disabled] [fullbleed]" [disabled]>
  <button type name? value? disabled?
    class="{variant} {size} [disabled] [fullbleed] [icon] [only-icon] [animation-fade]"
    [aria-label={tdsAriaLabel} when onlyIcon && tdsAriaLabel]>
    {text}<slot name="label"/><slot name="icon"/>
```

Base: `detail-02`, inline-flex, centred items, 1px transparent border, radius 4px, pointer.

| Size | Height | Padding | With icon | Only-icon padding | Icon box / margin-left |
|---|---|---|---|---|---|
| lg | 56px | 20px | 18px 20px | 17px | 20px / 20px |
| md | 48px | 16px | 14px 16px | 13px | 20px / 16px |
| sm | 40px | 12px | 10px 12px | 11px | 16px / 12px |
| xs | 24px | 4px 8px, font 12px | — | — | — |

`fullbleed` → width 100%, centred. Focus: `:focus` 1px outline focus-strong;
`:focus-visible` `tds-focus-state`. Disabled: opacity 0.25, `cursor: not-allowed`.
Hover/active only when not disabled.

| Variant | Background (light) default / hover / active | Text & icon | Border default / hover / active |
|---|---|---|---|
| primary | #16417f / #0f3263 / #041e42 | #fff | none |
| secondary | transparent | #000 | #0a2850a3 / #07275880 / #0e1013 |
| ghost | transparent | #000 | none / #07275880 / #0e1013 |
| danger | #d1001b / #b20018 / #8a0012 | #fff | none |

Focus state uses default background with hover text and border.

## Link — `tds-link` (shadow DOM)

Props (reflected): `disabled` (false), `underline` (true), `standalone` (false). Default
slot expects one `<a>`. On load only: disabled sets `tabindex="-1"` and
`aria-disabled="true"` on the slotted `<a>`.

```
<tds-link> #shadow: <span class="[disabled] [no-underline] [standalone]"><slot/></span>
```

`:host` inline; slotted `all: unset` (inherits font).

| State | Colour | Underline |
|---|---|---|
| default | #2a6ecf | yes |
| hover | #2a6ecf | no |
| `.no-underline` | — | none; underline on hover |
| `:focus-visible` | #2a6ecf | none; `box-shadow: 0 0 0 1px #fff, 0 0 0 3px #2a6ecf` |
| `:active` | #2a6ecf | yes |
| `:visited` | #16417f | decoration colour #16417f |

Disabled: opacity 0.25, `pointer-events: none`. Standalone: `detail-02`. Inside it a
`tds-icon` gets `padding-bottom: 4px; padding-left: 5px`.

## Spinner — `tds-spinner` (light DOM)

Props (reflected): `size` `'xs'|'sm'|'md'|'lg'` (`'lg'`), `variant`
`'standard'|'inverted'` (`'standard'`).

```
<tds-spinner size variant>
  <div aria-live="assertive" role="status" aria-label="loading">
    <svg class="tds-spinner-svg tds-spinner-svg-{size}" aria-hidden="true">
      <circle class="tds-spinner-circle tds-spinner-circle-{variant}"/>
```

SVG `2R` square, `transform: scale(-1,1) rotate(-90deg)`. Circle `cx = cy = R`,
`r = R − stroke/2`, `fill: none`, dash `2πR`, animation `dash` (`stroke-dashoffset −dash →
+dash`), `cubic-bezier(0.55,0.15,0.45,0.85)`, infinite.

| Size | Diameter | Radius | Stroke | Speed |
|---|---|---|---|---|
| xs | 16 | 8px | 3px | 1.8s |
| sm | 24 | 12px | 4px | 1.8s |
| md | 52 | 26px | 6px | 1.8s |
| lg | 84 | 42px | 8px | 2s |

Stroke: standard #2a6ecf, inverted #fff.

## Card — `tds-card` (shadow DOM)

| Prop (attr) | Type | Default |
|---|---|---|
| `modeVariant` | `'primary' \| 'secondary' \| null` | `null` |
| `imagePlacement` | `'above-header' \| 'below-header'` | `'below-header'` |
| `header`, `subheader` | `string?` | — |
| `bodyImg`, `bodyImgAlt` | `string?` | — |
| `bodyDivider` | `boolean` | `false` |
| `clickable` | `boolean` | `false` |
| `stretch` | `boolean` | `false` |
| `cardId` | `string` | random |
| `expandable`, `expanded` | `boolean` | `false` |

Event `tdsClick` (`{ cardId }`), only when `clickable`. Slots `header`, `subheader`,
`thumbnail`, `body`, `body-image`, `actions` (rendered only if present).

```
<tds-card>
 <(button if clickable | div) class="card [clickable] {imagePlacement}|{imagePlacement}-stretch"
     button: aria-label="{header || 'Card '+cardId}" aria-describedby="header-{cardId}">
  [below-header → HEADER]
  <div class="card-body" id="body-{cardId}">
    [body-image slot] [<img class="card-body-img">] [above-header → HEADER]
    [<tds-divider variant="discrete">] [body slot]
  </div>
  [actions slot]
HEADER = <div class="card-header [expandable] [expanded]">
  [thumbnail slot] <div class="header-subheader" id="header-{cardId}">
    [<span class="header">] [<span class="subheader">]
  [expandable: ghost sm tds-button, aria-expanded, chevron_down icon, rotated when expanded]
```

| Element | Rules |
|---|---|
| `.card` | shadow `0 3px 3px rgb(0 0 0/15%), 0 -1px 1px rgb(0 0 0/1%)`; bg #fff; width 100%; radius 4px; overflow hidden. Clickable hover: `0 -1px 1px rgb(0 0 0/5%), 0 3px 3px rgb(0 0 0/20%)`, pointer |
| `.card-header` | `headline-06`; padding 16px; flex, centred |
| thumbnail | 36×36, radius 100%, margin-right 16px, bg layer-03 |
| chevron | margin-left auto; `transform 160ms ease-in-out, opacity 120ms ease-in-out`; rotated 180deg |
| `.header-subheader` | column, gap 4px; header #0e1013; subheader #0a2850a3 |
| body image | width 100%, bg layer-03 |
| body | `detail-03`; colour #041530b8; padding 0 16px; margin 16px 0; max-width 336px |
| actions | flex; padding 16px; colour #0e1013 |
| inner button | width 100%, no border, left, padding 0; `:focus-visible` outline 2px #2a6ecf, offset −2px; `:active` shadow `0 -1px 1px rgb(0 0 0/5%), 0 1px 3px rgb(0 0 0/20%)` |
| stretch | card height 100%; body grows; body max-width unset |
| collapsed | expandable and not expanded → body hidden |
